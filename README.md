# Night Desk

An empty trading floor at night, 45 floors above Frankfurt, built with three.js in a single HTML file.
The terminal on the desk holds the site.

Live: https://topoftheblock.github.io

Edit the page text in the `<section data-page="…">` blocks near the bottom of `index.html`;
the terminal picks it up automatically. All market data on the screens is simulated.
